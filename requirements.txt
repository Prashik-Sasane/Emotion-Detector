# Emotion Detector

Emotion Detector is a simple Flask-based web application that analyzes text and predicts the dominant emotion using IBM Watson Natural Language Understanding (NLU) Emotion Analysis.

## Project description

This project demonstrates how to send text to the Watson NLP Emotion Analysis service and retrieve emotion scores for five categories:

- anger
- disgust
- fear
- joy
- sadness

The app identifies the dominant emotion from those scores and shows the result in a clean web interface.

## Technologies used

- Python 3
- Flask
- Requests
- IBM Watson NLP / Natural Language Understanding
- unittest
- Pylint

## Features

- Text input form for emotion analysis
- Emotion prediction using the Watson NLP service
- Returns scores for anger, disgust, fear, joy, and sadness
- Identifies and displays the dominant emotion
- Handles blank or invalid input gracefully
- Includes unit tests for emotion detection

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prashik-Sasane/Emotion-Detector.git
   cd Emotion-Detector
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## How to run the application

Start the Flask server:

```bash
python server.py
```

Then open:

```text
http://127.0.0.1:5000
```

## How to run unit tests

```bash
python -m unittest discover -v
```

## How to run Pylint

```bash
pylint server.py
pylint EmotionDetection/emotion_detection.py
```

## Watson NLP configuration

The project uses environment variables for the Watson NLP service. Set them before running the app:

```bash
export WATSON_API_KEY="your_api_key"
export WATSON_INSTANCE_ID="your_instance_id"
export WATSON_URL="https://api.us-south.natural-language-understanding.watson.cloud.ibm.com"
export WATSON_VERSION="2022-04-07"
```

If these values are not configured, the function safely returns an empty result instead of crashing.
